# 复杂问题邮件触发器

## 触发信号

### 多因素纠缠信号

当用户在邮件中描述的情况同时满足以下条件时触发：

1. **多因素纠缠**：问题涉及多个相互缠绕的因素（如工作 + 关系 + 情绪 + 健康 + 经济同时交织），用户难以分离。
2. **无法清晰表达问题**：用户自身无法明确说出"问题到底是什么"，表现为：
   - 反复切换话题和角度
   - 用了很多描述但始终没有定义核心问题
   - 说"我不知道从哪里说起"、"太乱了"、"一团糟"
   - 邮件内容很长但缺乏清晰的问题陈述

具体关键词和表达模式：

- "我也不知道问题到底是什么"
- "好乱"、"一团乱麻"、"说不清楚"
- "太多事情搅在一起"
- "我不知道从哪里开始说"
- "各种事情都有"
- 邮件中同时出现多个不相关领域的压力信号
- 问题陈述反复跳跃，缺乏主线

下列情况不触发：

- 用户能清晰描述一个具体问题（即便情感上很困扰），如"我想换工作但不知道怎么开始"。
- 用户已在 Chat/CLI 中进行了结构化对话。
- 用户只是列举多项待办事项（属 planning skill 范围）。
- 用户明确说"我就是想倾诉一下，不需要解决"。

## 回应模板

### 模板 A：问题模糊的轻量回应

```text
我读到你的邮件，感觉有很多事情在同时发生，而且它们好像缠在一起了。

这在面对复杂情况时很常见。在邮件里很难理清这种结构，但我们可以先从一件事开始：如果现在你只能说「最困扰你的是一件事」，那件事和什么有关？

不用给出完整答案。哪怕只是一个方向——工作、关系、身体、方向感——说出来，就是一个起点。

如果你想更深入地梳理，建议切换到 CLI/Chat。在对话里我可以帮你一步步把混乱拆开、把事实和假设分开、把能做和不能做的区分清楚。
```

### 模板 B：多领域压力交织的回应

```text
从你的邮件里我看到几个不同的压力方向同时在发生，这确实容易让人感到被淹没。

先不急着「解决」任何一件。我们可以先做一件事：把所有困扰你的事情列出来，然后一个一个看。

在 CLI/Chat 里我可以帮你：
1. 把所有的困扰都倒出来（不评价、不排序）
2. 区分哪些是事实、哪些是推断、哪些是情绪
3. 找到一条你能先动的线

在邮件里很难做这种结构化梳理。切换到 CLI/Chat，我们从头开始。现在你可以先做一件事：把你脑子里最吵的那个声音写下来——哪怕只是一句话。
```

### 模板 C：无法表达的回应

```text
有时候「说不清楚」本身就是最重要的信息。它说明问题确实复杂，而不是你能力不够。

在 CLI/Chat 里我不需要你一开始就把问题说清楚。我们可以从最模糊的感觉开始：

- "最近就是不对劲"
- "总感觉哪里有问题但说不上来"
- "好像所有事情都不对"

这些都可以作为起点。对话的过程本身就会帮你慢慢看清。

切换到 CLI/Chat，我们不用急着找答案，先一起把「一团乱麻」摊开看看。
```

### 模板 D：跨 skill 关联回应

当复杂问题同时涉及情绪、精力和方向感等多个 skill 时使用：

```text
你描述的状况涉及好几个层面——情绪、精力、方向感——它们互相影响，所以很难单点突破。

这种情况下最有效的方式不是分别解决每个问题，而是找一个「关键支点」——一个你稍微能控制、一动了它别的也会跟着变化的点。

在 CLI/Chat 里我们可以做一次全面的问题空间框定，把每个层面放进来一起看。切换过去吧，我会从这里继续。
```

## 何时引导用户到 CLI/Chat

以下情况必须在邮件中引导用户切换到 CLI/Chat 深度对话：

1. **问题无法清晰表述**：用户自己说不清楚问题是什么，邮件内容跳跃、混乱。
2. **多领域纠缠**：问题涉及 3 个以上不同领域且相互影响。
3. **需要结构化工具**：需要使用决策树、问题空间图、假设矩阵等可视化工具。
4. **情感负荷大**：用户表达出"被淹没"、"崩溃"、"不知道怎么办"等强烈情绪。
5. **需要多轮对话**：问题复杂到不可能在一次邮件回复中完成框定和方案设计。

### 不需要引导的情况

- 用户能清晰描述一个具体问题，即使用邮件 2-3 轮就能完成框定。
- 用户只是需要确认"这个情况确实复杂"——给予认可即可。
- 用户已在 Chat/CLI 中开始了对话，邮件只是补充信息。

## 引导用语

```text
这个话题涉及的因素比较多，在邮件里往返几轮可能都说不清楚。建议切换到 CLI/Chat，我可以帮你用更结构化的方式梳理。不需要你一开始就想清楚——我们一起从最乱的地方开始。
```

```text
复杂问题最好的处理方式不是「想清楚再行动」，而是「先框定再实验」。在 CLI/Chat 里我可以引导你走完这个过程。切换过去，我们从第一步开始：把你脑子里所有困扰一条条写出来。
```
