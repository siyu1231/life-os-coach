# 人生愿景邮件触发器

## 触发信号

以下邮件信号表明用户可能需要人生愿景教练技能的介入：

### 迷茫信号

- "我不知道自己想要什么。"
- "我觉得很迷茫，不知道下一步往哪走。"
- "生活好像还可以，但就是找不到方向。"
- "感觉自己在漂，没有目标。"
- "对什么事情都提不起兴趣。"

### 方向感缺失信号

- "我不知道要成为什么样的人。"
- "我找不到人生的意义。"
- "我为什么而活？什么对我重要？"
- "感觉做什么都可以，又做什么都不对。"
- "我搞不清楚自己到底想要什么。"

### 多次计划偏离且非执行问题

- "我定了好多目标，但都坚持不下来……但不是因为我懒，是做了一段时间觉得没意思。"
- "我执行能力没问题，但做几天就觉得这个方向不对。"
- "每次都下决心，每次都放弃，我觉得不是执行的问题，就是方向不对。"
- "每次列计划时很兴奋，做两周就怀疑这是不是我想要的。"

### 外部成功但内部空虚

- "我的工作不错，收入也还行，但总觉得没意思。"
- "在别人看来我过得挺好，但我知道自己没动力。"
- "我好像一直在满足别人的期待，从来没为自己活过。"
- "客观不错但主观空虚。"

### 意义感追问

- "生活的意义到底是什么？"
- "我觉得什么都没意义。"
- "不知道这么努力是为了什么。"
- "我好像掉进了一个虚无的感觉里。"

## 回应模板

### 模板 A：迷茫信号的轻量回应

```text
我听到了你的迷茫感。这种"不知道往哪走"的状态其实很常见，而且通常不是因为你不够好，而是因为方向本身就是需要探索的。

如果接下来你有时间，我建议你打开 Chat 或 CLI 模式，我们可以一起做一次人生愿景对话。不需要你立刻有答案，我们一起从你当下的感受开始，看看哪些方向值得认真探索。

在那之前，你可以先想一个问题：这份迷茫感最近是在哪个具体场景里冒出来的？
```

### 模板 B：方向感缺失的轻量回应

```text
找不到方向是很多人都会经历的阶段，这不代表你有问题。方向感不是天生就有的，它是从尝试、感受和反思中长出来的。

这个话题在 Email 里聊比较受限，我建议你切换到 Chat 或 CLI 模式，我们做一次完整的人生设计对话。我们可以从收集你最近的"生命力时刻"开始——那些让你觉得"这才像我"的小事。

现在可以先问自己：过去一个月，有没有哪怕十分钟，让你觉得"这样活着还不错"？
```

### 模板 C：多次偏离非执行问题的轻量回应

```text
你提到多次计划偏离，而且不是执行力的问题，这说明你的方向感可能需要先被澄清，而不是再学一套执行技巧。当计划本身缺乏意义感或吸引力时，再好的执行方法也无法持续。

这个情况很适合在 Chat 或 CLI 里做一次深入对话，我们可以：
1. 先找出你真正在意的价值
2. 看当前目标和这些价值是否一致
3. 设计一个能给你真实反馈的小实验

请切换到 Chat 或 CLI，我们详细聊。
```

### 模板 D：外部成功内部空虚的轻量回应

```text
你描述的"外部指标不错但内心没被点亮"的状态很真实，这不矫情。这里需要区分两件事：客观获得的东西（收入、身份、安全感），和它没有给你的东西（自主、创造、意义、真实关系）。

建议你切换到 Chat 或 CLI，我们做一次价值观澄清对话。你可以先准备：过去半年里，有没有三件小事让你觉得"这才像我"？
```

### 模板 E：意义感追问的轻量回应

```text
"人生意义"是一个很大的问题，我们可以先把它换成一个更有操作性的问题：意义通常在哪些具体时刻出现？你不需要先有一个宏大使命，很多人的方向是从小意义里长出来的。

这个话题适合深度对话，请切换到 Chat 或 CLI，我们慢慢聊。你可以先记录：未来三天，每天记一个觉得"这件事有点值得"的瞬间。
```

## 何时引导用户到 Chat

以下情况必须在邮件中引导用户切换到 Chat 或 CLI 深度对话：

1. **情感强度高**：用户表达的迷茫、空虚或焦虑情绪强烈，邮件碎片化讨论不足够。
2. **问题复杂度高**：涉及多重价值冲突、多路径选择、身份转变等复杂议题。
3. **需要持续对话**：愿景设计通常需要多轮对话、反馈和实验复盘，不适合一次邮件。
4. **出现安全风险**：用户表达自伤或伤害他人的信号，立即引导到 Chat 并由教练介入。
5. **用户表达深度需求**：用户说"这个问题很大""我不知道从哪里说起""我需要慢慢聊"。

### 不需要引导的情况

- 用户只是想确认方向感问题的合理性，给予简短认可即可。
- 用户问了具体的愿景澄清问题，可以用 2-3 轮邮件回答。
- 用户已经在 Chat/CLI 对话中，邮件只是补充记录。


```text
你提出的问题很大，值得认真对待。建议你打开 Chat，我们可以从你最当下的感受开始，一步步看。你现在已经迈出了重要的一步——承认迷茫并开口。
```
