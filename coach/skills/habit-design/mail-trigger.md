# 习惯设计邮件触发器

## 触发信号

### 同一偏离连续出现信号

当系统在用户复盘记录中检测到同一行为偏离连续出现 **3 次或以上**时触发。

具体触发条件：

- 用户在连续 3 次或以上的复盘（日复盘/周复盘）中提到同一习惯未能执行
- 同一行为偏离模式反复出现（如"又没运动"、"又熬夜了"、"又没写日记"）
- 偏离原因相似或相同（如"太累了"、"忘记了"、"没时间"）

下列情况不触发：

- 偏离仅出现 1-2 次（仍在正常波动范围内）
- 偏离原因每次不同且用户已自行调整
- 用户明确表示"这段时间先不做这个习惯"
- 用户在 Chat/CLI 中已经对该习惯进行了重新设计

## 回应模板

### 模板 A：偏离初现（连续 3 次）

```text
我注意到你在最近 3 次复盘中都提到了「{行为名称}」没能按计划执行。

这不代表你不够自律——可能是这个习惯设计本身需要调整一下。我们来一起看看：

1. 这个习惯现在还重要吗？——如果它的意义已经变了，调整目标完全没问题。
2. 它在哪个环节卡住了？——是忘了（缺提示）、太累了（能力不足）、还是没动力（动机不够）？
3. 如果把它缩小到「再累也能完成」的版本，那会是什么样？

如果你想深入聊，切换到 CLI/Chat 模式，我们可以一起重新设计这个习惯。现在可以先告诉我：上面三个问题里，哪个最能描述你的情况？
```

### 模板 B：偏离持续（连续 5 次及以上）

```text
我注意到「{行为名称}」已经连续 5 次在复盘中出现偏离了。这可能不是「执行」的问题，而是「设计」的问题。

当一个行为反复做不成时，最有用的不是更用力，而是换一个角度问问：

- 这个习惯的线索还在吗？——当初设的触发条件现在还成立吗？
- 它的「最小版本」够小吗？——如果累到只想躺平，这个版本还能做吗？
- 有没有可能有另一个行为能达到同样的目的，但更匹配你现在的节奏？

这些问题在邮件里不太容易展开。建议你切换到 CLI/Chat，我陪你一步步重新设计。现在你可以先告诉我：最让你沮丧的是「做不成」本身，还是「觉得自己不该做不成」？
```

### 模板 C：跨 skill 关联——偏离伴随精力问题

当偏离同时涉及精力管理信号时使用：

```text
我注意到「{行为名称}」连续几次没完成，同时你这段时间也在说精力不足。

这两个信号放在一起看，可能不是这个习惯有问题，而是你目前的容量暂时撑不起它。我们先不急着调整习惯本身，先把精力状态看一下——有时候恢复够了，习惯自然就回来了。

建议切换到 CLI/Chat，我们可以同时从精力管理和习惯设计两个角度一起看。
```

## 何时引导用户到 Chat

以下情况必须在邮件中引导用户切换到 CLI/Chat 深度对话：

1. **偏离模式复杂**：涉及多个习惯同时偏离，需要整体分析习惯系统而非单个习惯。
2. **情感反应强烈**：用户对偏离表现出明显的自责、挫败或"我就是做不到"的自我否定。
3. **需要重新设计**：偏离的根本原因不是执行问题，而是习惯设计本身需要重构（线索、能力、动机）。
4. **跨 skill 关联**：偏离可能与精力、情绪、环境变化等其他因素纠缠。

### 不需要引导的情况

- 用户只是简单汇报偏离，无情绪困扰，且偏离仅 1-2 次。
- 用户在邮件中已经给出了自己的分析和调整方案，只需确认。
- 用户明确表示只是记录，不需要干预。

## 引导用语

```text
这个话题涉及多个习惯和它们之间的关联，在邮件里不容易展开。建议切换到 CLI/Chat，我们一起把习惯系统梳理一遍。你可以先告诉我：最近最让你困扰的一个偏离是什么？
```

```text
习惯反复偏离通常是设计问题，不是意志力问题。这不是一两封邮件能解决的——切换到 CLI/Chat，我帮你从行为方程式的角度重新看看。
```
