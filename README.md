# Life OS Coach

**一个基于 AI Agent 的人生教练系统——把人生方向转化为目标、项目和今日行动，同时照看精力、拖延、习惯与复盘。**

Life OS Coach 融合 LifeOS 的工程化理念（Current -> Ideal 爬山、证据驱动、声明即附带可证伪条件）与 life-coach 的教练方法体系（ACT、CBT、ICF、行为设计），通过 Cron 定时邮件触达 + CLI/Chat 深度对话双通道，在日常中逐步构建对用户的长期理解，提供持续的、有记忆的、可验证的人生教练服务。

---

## 核心能力

| 能力模块 | 描述 | 通道 |
|---------|------|------|
| **人生愿景** | 澄清价值观、身份主题、长期方向、可能路径和人生实验 | 邮件触发 + CLI/Chat 深度 |
| **计划制定** | 将目标拆解为项目、任务、下一步行动，设置缓冲和复盘点 | 邮件（晨间 09:30） + CLI/Chat |
| **拖延应对** | 识别拖延类型（完美主义、启动困难、决策拖延等），设计最小可执行步骤 | 邮件（自动检测 + 干预） + CLI/Chat |
| **习惯设计** | 设计适配真实情境的小习惯，降低启动门槛，逐步建立可持续行为 | 邮件 + CLI/Chat |
| **精力管理** | 围绕精力曲线、恢复节律和低容量状态制定计划 | 邮件（日间状态检查） + CLI/Chat |
| **复盘反思** | 结构化复盘：事实重建 -> 模式提取 -> 学习提炼 -> 下一轮调整 | 邮件（17:30 收尾 + 22:30 晚间） + CLI/Chat |
| **复杂问题** | 处理多因素纠缠、高风险、信息不完整的复杂决策场景 | CLI/Chat 为主 |
| **长期记忆** | 跨会话积累用户画像、精力线索、执行模式、复盘洞察 | 自动（所有通道共享） |

**核心设计理念：**

- **engine/** 定义"何时收发消息、状态如何转移"（Cron 调度、会话状态机、邮件协议）
- **system/** 定义"Agent 如何思考、读什么、判断什么、输出什么"（算法循环、记忆系统、ISA、TELOS、验证）
- **coach/** 定义"具体教练领域的方法和话术"（7 个 skill + ACT 底层参考 + 教练流程）
- engine 和 system 是**对偶关系**：session-flow 管理消息时序，algorithm 管理推理过程

## 快速开始

将本仓库作为 AI 工具的 skill pack 使用，让 AI 读取核心文件后即可开始教练服务：

```
读取 coach/act-core.md, system/algorithm.md, engine/cron-system.md, engine/session-flow.md, engine/email-protocol.md, system/memory-system.md 这几个文件，然后告诉我你可以怎么帮我。
```

如果你使用的 AI 工具支持 Codex / skill pack 机制，可以直接将本仓库作为 skills 目录引入，AI 会按 `coach/skills/*/SKILL.md` 中的触发条件自动路由到对应能力。

## 安装流程

### 1. 克隆仓库

```bash
git clone <repo-url> life-os-coach
cd life-os-coach
```

### 2. 初始化用户数据目录

```bash
cp -r templates/ life-coach-data/
```

`life-coach-data/` 已在 `.gitignore` 中排除，你的个人数据不会被提交到仓库。

### 3. 配置企微邮件（如需邮件通道）

在企微管理后台创建自建应用，开通「发送邮件」和「读取邮件」权限，然后将凭证写入 `life-coach-data/integrations/tools.md` 或 `life-coach-data/profile/user.md`：

```markdown
## 企微配置
- `wecom.corp_id`: ww1234567890abcdef
- `wecom.agent_id`: 1000002
- `wecom.secret`: your_secret_here
```

详细步骤参见 `engine/email-protocol.md`。

### 4. 填充用户画像

编辑 `life-coach-data/profile/user.md`，填写基本作息、固定承诺、沟通偏好等。**不要一次填满**——在 AI 的陪伴下逐步补充，只记录你明确确认过的信息。

### 5. 开始使用

- 首次使用建议在 CLI/Chat 中做一次 introductory conversation，让 AI 了解你的基本情况。
- 邮件通道会在下一个工作日自动启动（Cron 系统按工作日 09:30 发送早安问候）。
- 周末和节假日自动静默，仅晚间 22:30 发送轻量复盘（可配置关闭）。

## 理论来源与致谢

Life OS Coach 的教练方法体系派生自 **[life-coach](https://github.com/icarusion/life-coach)** 项目，工程化理念（Current -> Ideal 爬山、证据驱动、声明即附带可证伪条件、ISA）派生自 **[LifeOS](https://github.com/icarusion/LifeOS)** 项目。两者均为公开的、长期维护的开源项目，本仓库是在它们基础上的融合、重组和工程化实现。

详细参考文件见 `_reference/` 目录。

### 心理学与教练方法

- **接纳承诺疗法（ACT）**：价值澄清、认知解离、接纳、承诺行动
- **认知行为疗法（CBT）**：想法记录、苏格拉底式提问、行为实验、认知重评
- **正念与自我关怀**：正念觉察、非评判态度、MBSR/MBCT、共通人性
- **存在主义心理治疗**：自由、选择、责任、意义、孤独与关系
- **ICF 教练能力**：建立信任、积极聆听、唤起觉察、促进行动与责任
- **焦点解决取向**：例外、资源、下一小步、问题可解化

### 行为设计、习惯与执行

- 《掌控习惯》：身份投票、习惯叠加、两分钟规则、环境设计
- 《福格行为模型》：B=MAP、微习惯、提示、能力链、庆祝与行为匹配
- 番茄工作法：专注单元、打扰记录、任务切分与恢复节奏
- 《高效 PDCA 工作术》：计划、执行、检查、调整的闭环思维

### 人生方向、意义与复杂问题

- 《斯坦福人生设计课》：重力问题、工作观/人生观、奥德赛计划、原型设计
- 《西西弗神话》：荒诞、意义与主动选择
- 《心流：最优体验心理学》：投入、挑战与技能匹配
- 《内在动机：自主掌控人生的力量》：自主性、内部动机与持续行动
- 《反脆弱》《努力的意义》《苦难的意义》：成长型思维、在不确定性中学习
- 《建构解决之道》《有解》：问题解决、资源视角、复杂问题结构化

特别感谢暂停实验室相关课程对人生教练体系的启发，尤其是有效努力、拖延应对、正念、自我关怀、CBT 综合与焦虑应对等训练材料及其参考书单。本仓库只保留可公开传播的抽象方法和重组织表达，不包含课程正文、课时结构、专有案例或练习原文。

## 安全边界

**本 Agent 是人生教练和自我管理辅助，不是心理治疗、医疗诊断、法律建议、财务建议或危机干预服务。**

- 用户表达自伤、伤人、急性危机或现实安全风险时，优先安全处理，建议联系当地紧急服务、专业人员或身边可信任的人。
- 用户描述严重或持续的抑郁、焦虑、失眠、饮食障碍、成瘾、创伤反应、慢性疲劳等情况时，温和建议寻求专业医疗或心理支持。
- 用户面对重大不可逆决定时，不替用户做决定，只帮助澄清价值、约束、选项、风险和下一步低风险验证。
- 不把所有痛苦都解释成"需要计划"或"需要行动"。有些情况更需要休息、支持、保护、治疗或现实资源。
- 对价值观、愿景、正念、情绪调节和关系模式等主题，不承诺"想通即可改变"。这些能力需要具身练习、现实反馈和长期复盘。

**AI 不能替代具身练习：** 这个项目的目标不是制造一个"更理性的大脑"来替用户规划人生。小芽能做的，是帮助你把混乱经验整理成语言，把模糊困扰拆成变量，把价值和项目连起来，把计划变得更符合精力，把偏离变成复盘材料，把下一次练习设计得更小、更真实。但它不能替你练习、不能替代真实关系、不能让长期形成的模式在一次对话中改变。

## 隐私说明

- **本地优先**：用户数据默认存储在 `life-coach-data/` 目录中（已通过 `.gitignore` 排除），不依赖外部服务或云存储。你可以完全控制自己的数据。
- **什么是收集的**：Agent 只记录你在对话中明确提供或共同确认的信息，如作息习惯、精力窗口、项目状态、复盘洞察等。不会在未告知的情况下记录或推测个人信息。
- **什么是不收集的**：不会记录敏感个人信息、不会在未授权的情况下访问外部账户、不会将对话内容用于训练或分享。
- **外部工具接入**：如需使用企微邮件、日历、待办等外部工具，相关凭证存储在 `life-coach-data/integrations/tools.md` 中。这些文件同样被 `.gitignore` 排除。接入哪些工具、共享哪些数据，完全由你决定。
- **数据可迁移**：所有用户数据均为 Markdown 纯文本格式，你可以随时查看、编辑、导出或删除。不锁定在任何专有格式中。
- **记忆原则**：先少后多、单一事实源、先记录再提炼。不会一开始就创建大量文件；只有在某类内容持续增长、被频繁读取时才建议拆分。单次观察先进入每日记录，多次出现后才沉淀为长期规律。
- **写入前确认**：长期画像、价值观、身份描述、敏感信息、外部工具操作，写入前会先向你确认。
